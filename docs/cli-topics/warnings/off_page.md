code: off_page
availability: needs `--layout`
summary: A layout block bbox extends beyond the page.
---

`blockIndex` names the block, and the message names the sides it crosses with the page and block boxes. When the block's text run also reaches the page edge, `page_edge_text_truncated` replaces this warning on that block. It can also be a geometry symptom of `duplicate_text_layer`.
