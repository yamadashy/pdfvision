## Showcases

Hard for PDF extraction, yet read correctly or recovered through a warning that names the next step.

- `beamer-overlays` — Beamer deck with a frame built up over four overlay pages (hidden-overlap, page-geometry, structure). every overlay page carries the text of all four items, the unrevealed ones only drawn at 15% opacity, and the content shared by the steps of one frame looks like repeated page chrome
- `econ-regression-table` — Regression table with standard errors and stars (tables). Two-line cells (coefficient over a parenthesised standard error) with superscript stars and no rules between rows make row boundaries ambiguous, so table detectors drop or merge rows.
- `magazine-feature` — Magazine feature opening page (reading-order, structure). Three columns are cut into segments by a pull quote across two of them, an inset photo with text run around it and a tinted sidebar, so reading by position alone splices sentences across columns.
- `math-display` — Physics paper page with display equations (math). display equations are runs on several baselines joined only by vector fraction bars, hanging operator glyphs and bracket strokes; read as lines they scatter across the page with their numbers among the page numbers
- `paper-author-grid` — Paper first page with an author grid and a sideways arXiv stamp (reading-order, structure, vertical-rotated). The author blocks share baselines across the row, so neighbouring emails sit closer than a column gutter and the stacks look like text columns; each mark is a raised run in another font.
- `pleading-line-numbers` — Court motion on pleading paper with line numbers (structure, reading-order, tables). The margin numbers are page-template text written before the body, on a grid the single-spaced blocks do not follow, so reading by stream or by position interleaves them with the text they number.
- `reconciliation-wide` — Landscape GAAP to non-GAAP reconciliation (tables, page-geometry). A three-level centred header spans two column groups on a landscape page, with `$`, parenthesised negatives, `—` placeholders and footnote markers each set as separate glyphs that must be reattached to the right value.
- `ruby-yasashii-ja` — City notice in easy Japanese (やさしい日本語) with furigana over every kanji (scripts, structure). Every kanji word carries half-size kana on a baseline of its own between the text lines, so a reader that groups text by baseline emits a line of stray kana above every line, or splices the readings into the sentence.
- `scan-ocr-layer` — Scanned letter with an imperfect OCR text layer (raster-text, hidden-overlap). The only text is an invisible OCR layer under a scanned image, and its errors (`retumed`, `l4`, a dropped line) look like ordinary native text.
- `slides-landscape` — Three-slide 16:9 deck with a screenshot slide (page-geometry, raster-text, vector-meaning). One slide is a screenshot with a table baked into its pixels, so its native text is only the footer and the slide number while the page looks full.
- `stat-table-broken-font` — Statistical release table with a figure font that has no ToUnicode (encoding, tables, page-geometry). The figure font has no ToUnicode map, so every value extracts as raw glyph indices while the page renders perfectly and the labels around the values extract normally.
- `symbol-font-signs` — Results page whose symbol font maps signs to the wrong characters (encoding, tables). The symbol font’s ToUnicode map names ordinary characters for every sign, so the text layer is well-formed and plausible while −52% reads as 252% and < as a comma.
- `table-empty-cells` — Table with empty cells under grouped headers (tables). Rows leave value cells empty under grouped headers, so a reader that assigns columns by order rather than by x position shifts every later value one column left.
- `table-group-headers` — Statement with section rows and a two-level header (tables). Sub-labels such as `Products` and `Services` repeat under value-less section rows, so a row only means something if the section row above it stays in place.
- `tategaki-book-spread` — Vertical novel spread (縦組み見開き) with ruby (vertical-rotated, reading-order, structure). each glyph is a separate text object placed down its column, so 縦中横 digits, vertical dashes and blank em boxes look like breaks, and a two-page spread has to be read right page first
- `tax-form-digit-grid` — Tax-return form (確定申告書) with digit grids (tables, vertical-rotated, structure). Every amount is a row of single digits in ruled boxes, overlaid after the template, so nothing but geometry ties a number to its label or its stacked section band.
