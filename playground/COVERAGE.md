## Showcases

Hard for PDF extraction, yet read correctly or recovered through a warning that names the next step.

- `reconciliation-wide` — Landscape GAAP to non-GAAP reconciliation (tables, page-geometry). A three-level centred header spans two column groups on a landscape page, with `$`, parenthesised negatives, `—` placeholders and footnote markers each set as separate glyphs that must be reattached to the right value.
- `scan-ocr-layer` — Scanned letter with an imperfect OCR text layer (raster-text, hidden-overlap). The only text is an invisible OCR layer under a scanned image, and its errors (`retumed`, `l4`, a dropped line) look like ordinary native text.
- `stat-table-broken-font` — Statistical release table with a figure font that has no ToUnicode (encoding, tables, page-geometry). The figure font has no ToUnicode map, so every value extracts as raw glyph indices while the page renders perfectly and the labels around the values extract normally.
- `table-empty-cells` — Table with empty cells under grouped headers (tables). Rows leave value cells empty under grouped headers, so a reader that assigns columns by order rather than by x position shifts every later value one column left.
- `table-group-headers` — Statement with section rows and a two-level header (tables). Sub-labels such as `Products` and `Services` repeat under value-less section rows, so a row only means something if the section row above it stays in place.
